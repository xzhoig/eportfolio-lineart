VISUAL DESIGN
The complete site and all four adapted demos use warm off-white paper,
black ink, thin ruled frames and grids, small uppercase monospace labels,
and one orange-red accent. The original inline IT and AI illustration series
uses retro computers, open server hardware, circuits, browser interfaces,
technical books, and neural-network motifs. Each main page has a distinct
engraving, and the tutorial demos include matching technical studies. All
illustration and project-preview SVG geometry was created for this website.
The supplied Heron screenshot informed the visual direction; no website assets were copied.
CSS and vanilla JavaScript power the motion without any CDN dependencies.
The hero terminal is decorative: hovering over the computer types sample
code; the Wake terminal button provides the same control on touch screens
and from a keyboard. Sleep terminal returns it to the neural diagram.
Reduced motion shows complete code immediately and disables moving data
dots. Circuit-frame details occupy the gutters and do not intercept input.
